# Nexora v1.0.1 — Release notes

## Status

This document records the current source changes since the v1 baseline. The working-tree `package.json` specifies `1.0.1`; this version change was already present when these notes were written. A package version or source change alone does not establish a published release, deployment, migration, or production verification.

## File management

- **File clipboard:** Copy and Cut support multiple selected files or folders; Paste uses the existing Copy or Move API in the current folder. Copy remains available for repeated pastes. Successful cuts are removed from the clipboard; failures remain for retry. Cross-storage paste is unavailable, and folder moves reject known descendants or destinations with unverifiable ancestry.
- **Keyboard shortcuts:** Ctrl/Command+C, X and V perform clipboard actions outside editable fields; Escape clears the clipboard. The clipboard exists only in authenticated workspace memory and is discarded on logout, expiry, account change, workspace unmount, or reload. Cut items are faded.
- **Trash:** Delete permanently all loads a snapshot across Trash pages and requests irreversible confirmation before deleting items through the existing per-item API. Results may be partial; items added after the snapshot are excluded. Refresh and retry failures as needed.
- **Preview:** MP4, WebM and Ogg video is supported through the existing on-demand preview route for connected files and public shares, subject to browser codec support. Video, images and PDF are limited to 20 MiB; text remains limited to 1 MiB. Video is buffered before playback; larger files remain downloadable. HTML CSP permits blob media while retaining nonce-based script policy.
- **File Browser refinements:** File type icons, a non-interactive Favorites column heading, more space between Size and row actions, hover and keyboard highlights for row actions and New menu, dismissible feedback, and selection controls below the toolbar. The Copy/Move destination picker supports creating a folder when permitted. Successful upload queue entries are removed automatically after five seconds.

## Workspace and sharing

- Activity icons distinguish move, creation, copy, upload, public-link replacement, and permanent deletion by color in light and dark themes. Action text remains available.
- Dashboard, Recent, Favorites, Trash and Shared distinguish folder and file icons by color; unavailable shared items have a neutral icon. The mobile Sidebar slides in and out and respects reduced-motion preferences. The shared preview dialog uses a medium maximum width on larger screens.
- Public links support expiry with server-side enforcement and session-only access to the newly created or replaced link. Existing links cannot be recovered after their secret leaves memory; replacement invalidates the previous link. Expiry adds migration `0004_public_share_expiry.sql`; its production application and this release's deployment are not verified here.
- The HTML middleware uses a per-response nonce for Cloudflare JavaScript Detections while keeping a restrictive CSP. The 2026-10-28 all-functions production smoke result is operator-confirmed, not tool-verified, and does not establish that this revision is deployed.

## Validation and limitations

- Earlier work in this chat passed `pnpm lint` and `git diff --check` for each change. Video preview's targeted backend, frontend-storage and security-header tests passed 95/95. The clipboard utility tests passed 2/2.
- The full test suite previously failed in public-share tests, including share creation returning HTTP 400 instead of the expected 201. Those failures were not resolved or rerun for this document. Clipboard keyboard/session flows, bulk permanent deletion, video playback, responsive UI, and live-provider behavior still require integration or browser QA.
- Folder aggregate size remains unavailable; it is not estimated from partial listings. Storage usage remains “Not reported” unless authoritative metrics are supplied. Existing backup, restore-drill and production security gates remain in [the v1 baseline](V1_RELEASE.md) and [Phase 10.1.1](PHASE_10_1_1.md).
- This documentation update did not deploy, apply migrations, change production data or verify live infrastructure. No new build or full test run was performed for the notes.
